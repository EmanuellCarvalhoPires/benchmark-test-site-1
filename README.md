# Benchmark Test Site

Repositório de teste idêntico criado para conduzir testes comparativos de consumo de tokens, tempo de execução e eficiência de requisições Git / GitHub entre:
- **AI Git Tools** (módulo do ecossistema com retorno estruturado e truncamento).
- **Claude Code nativo** (comandos diretos de terminal e ferramentas padrão).

## Arquivos do Projeto
- `index.html`: Página principal com navegação, hero e cards.
- `styles.css`: Estilização responsiva com variáveis e modo escuro.
- `app.js`: Script de interatividade (tema e contador).

## Branches e PRs de Teste
- `main`: Branch de produção / padrão.
- `feature/feedback-form`: Branch com Pull Request aberto para testar listagem e inspeção de PRs.
